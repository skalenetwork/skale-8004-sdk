# skale8004-ts
Clean TypeScript foundation for blockchain interactions.
## Packages
- `@skalenetwork/8004`: core SDK and domain models.
- `@skalenetwork/8004-adapter-viem`: viem adapter.
- `@skalenetwork/8004-adapter-ethers`: ethers v6 adapter.
- `@skalenetwork/8004-adapter-web3`: web3.js adapter.
- `@skalenetwork/8004-skale-x402-proxy`: x402-gated SKALE ERC-8004 proxy helper.
- `@skalenetwork/8004-cli`: polished CLI for developer workflows.
## Quickstart
```bash
pnpm install
pnpm build
pnpm check
```
## Everyday commands
```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm check
pnpm dev:cli
```
## Examples
```bash
pnpm example:core
pnpm example:adapters
pnpm example:all
```
